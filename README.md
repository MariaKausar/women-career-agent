# 👩‍💼 Women Career Agent

A simple AI agent built to help women with job hunting and career progress.
Built with Python as a first AI agent project.

## 💡 What It Does

This agent helps women navigate their career journey by providing:

- 📄 **CV & Resume Tips** — How to write a strong CV that gets noticed
- 🎤 **Interview Preparation** — Tips and practice questions for interviews
- 🔍 **Job Hunting Advice** — Where to search and how to apply effectively
- 📚 **Skills Guidance** — What skills to learn for the tech industry
- 💰 **Salary Negotiation** — How to negotiate your worth confidently
- 💪 **Motivation** — Encouragement when you need a confidence boost
- 📈 **Progress Tracking** — Weekly goals to stay on track
- 🤝 **Networking Tips** — How to build your professional network

## 🚀 How To Run

Make sure you have Python installed, then run:

```bash
python women_career_agent.py
```

## 💬 How To Use

Once the agent is running, type any of these:

| Command | What You Get |
|---|---|
| `cv` | CV and Resume tips |
| `interview` | Interview preparation |
| `job` | Job hunting tips |
| `skills` | What skills to learn |
| `salary` | Salary negotiation advice |
| `motivation` | A confidence boost! |
| `progress` | Weekly career goals |
| `network` | Networking tips |
| `help` | See all commands |
| `quit` | Exit the agent |
